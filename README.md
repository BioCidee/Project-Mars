## 🇫🇷 Description (FR)

Courte présentation du projet :

- Objectif : Mini RTS, vous devez organiser la prise de ressources et la défense de Mars contre de méchants aliens !

Note :
- Génération procédurale avec gestion de la hauteur et de l'adoucissement des pentes, ainsi qu'une gestion par seed.
- Gestion des ressources
- Gestion du gameplay : placement de structures façon "Clash of Clans" (choix du bâtiment à construire, puis placement libre sur la carte)

# Project Name : Project Mars

## Status: Under development (PAUSED - Currently away from home for studies)

## 🇬🇧 Description (EN)

Short introduction of the project:

- Purpose: Mini RTS, you must organize resource gathering and the defense of Mars against evil aliens!

Note:
- Procedural generation with height and slope smoothing management, as well as seed-based generation.
- Resource management
- Gameplay management: building placement in a "Clash of Clans" style (choose the structure to build, then place it freely on the map)
- Enemy AI: enemies spawn in waves and target the nearest building, or head straight for the mothership; the game is lost if it's destroyed

Main technologies: Unity, C#, Git
Asset by: KENNEY
